# MotoGP-Historical-Dataset

A historical **MotoGP / 500cc racing dataset** collected using Python and the MotoGP API.

## 📌 Overview

This repository contains MotoGP race data from **1949 to 2025**, including rider, team, manufacturer, race position, grid position, points, and event information.

## 📅 Coverage

* **1949–1979**
* **1980–1989**
* **1990–1999**
* **2000–2004**
* **2005–2009**
* **2010–2019**
* **2020–2025**

## 🛠️ Technologies

* Python
* Pandas
* Requests
* OpenPyXL
* MotoGP API

## 📊 Uses

The dataset can be used for:

* MotoGP performance analysis
* Rider & team statistics
* Data visualization
* Machine learning
* Historical race analysis

## ⚠️ Note

Data availability and structure may vary between historical seasons, especially between the **500cc and modern MotoGP eras**.

## 🎯 Goal

To provide an organized historical MotoGP dataset for **data analysis, visualization, and research**.
